# Smart Expenses Management System

A web-based application developed to help users efficiently manage their **income, expenses, budgets, and spending activities** in one place.

## 📌 About the Project

The **Smart Expenses Management System** provides a simple and organized way for users to keep track of their financial activities.

The system allows users to register and log in, add income and expenses, monitor their spending, manage budgets, and view financial reports.

## ✨ Features

* 🔐 User Registration & Login
* 💰 Income Management
* 💸 Expense Management
* 📊 Expense Tracking
* 🎯 Budget Management
* 📈 Spending Monitoring
* 📋 Income & Expense Reports
* 👤 User-specific financial data
* 🚪 Logout functionality

## ⚙️ Prerequisites

Make sure the following are installed on your system:

* Java JDK 17 or above
* MySQL
* Git
* Eclipse or VS Code
* Web Browser

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Smart-Expenses-Management-System.git
```

### 2. Open the Project

Open the project in **Eclipse** or **VS Code**.

### 3. Configure MySQL

Create the required database in MySQL and update the database configuration with your local MySQL username and password.

### 4. Run the Backend

Open the terminal inside the project and navigate to the backend folder:

```bash
cd backend
```

For Windows:

```bash
.\mvnw.cmd spring-boot:run
```

Or, if Maven is installed:

```bash
mvn spring-boot:run
```

### 5. Access the Application

After the backend starts successfully, open the application in your browser using the configured application URL.

## 📊 Main Modules

### User Management

Allows users to register, log in, and access their personal financial information.

### Income Management

Users can add and manage their income records.

### Expense Management

Users can record and manage their daily expenses.

### Budget Management

Users can set budgets and monitor their spending against the allocated budget.

### Spending Monitoring

Helps users keep track of their spending activities.

### Reports

Provides organized information about income and expenses for better financial understanding.
